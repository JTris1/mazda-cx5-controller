Firmware update

    
This controller is running a new firmware on probation. It is confirmed after 3 minutes of healthy running (cellular, tunnel and API up). If it restarts or never gets healthy, it goes back to the previous firmware by itself.

    
Choose the firmware.bin built by PlatformIO (.pio/build/<env>/firmware.bin). The browser checks it, signs its hash with your key, then uploads it to the spare slot. Nothing changes until you restart. Refused while a command runs or the engine is on.
